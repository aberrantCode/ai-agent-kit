Asset Lifecycle
Author
Write skill, instruction, or command in ai-agent-kit (archive)
→
Deploy
Profile install OR project install via /install-skill
→
Consume
User's profile or a project repo invokes the asset
Flow Direction
Every asset is authored once, lives here, and deploys out to a profile or a project. The flow is always archive → consumer.
Core Surfaces
claude/
Canonical authoring surface. Primary source. Skills, instructions, and commands all live here.
codex/ · gemini/
Mirrors of the Claude surface. Codex: on-demand. Gemini: frozen. Dual-CLI support.
shared/
Vendor-neutral assets: prompts, workflows, configs, plugins. Used by all surfaces.
Governance & Automation
docs/
Requirements, plans, feature specs, and binding reorg governance. CAP-ID registry. Single source of scope authority.
scripts/
Lifecycle automation: audit skills, generate CATALOG.md and manifest.json, install to profiles/projects, sync archives.
Generated artifacts
CATALOG.md, manifest.json. Source of truth for asset inventory. Never manually edited.
