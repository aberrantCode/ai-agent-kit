Vendor Mirror Flow

Canonical authoring → on-demand mirrors → frozen exports · one-way sync

Core Concept

The claude/ directory is the canonical authoring surface. Skills authored here flow downstream to codex/ (on-demand mirror, created when actually used) and gemini/ (frozen mirror, grows only by deliberate decision). Every mirror carries a source-version stamp referencing the Claude skill/version it was mirrored from. The /audit-skills command watches both paths for staleness and reports gaps informationally, never as a failure.

Mirror Mechanics
codex/ is on-demand
Created manually by running a mirror command only when a skill is actually used from Codex. Does not exist by default. Each mirror carries a source-version stamp referencing the Claude skill name + version it was mirrored from.
gemini/ is frozen
Frozen at its current set of skills. New Claude skills are NOT automatically mirrored here. Growing this set is a deliberate, manual decision made by the maintainers.
Flow is one-way only
claude/ → codex/ → (never backwards). claude/ → gemini/ → (never backwards). Mirrors never push changes back to the source.
audit-skills · Gap Detection & Staleness Reporting
The /audit-skills command is the observation lens. It watches both the claude→codex and claude→gemini paths by comparing each mirror's source-version stamp against the current Claude original.
Reporting is informational
Gaps and staleness are reported for human awareness, never as a CI failure or blocker.
Timestamp-based staleness
Detects when a mirror's source-version stamp is older than the current Claude skill version, indicating the mirror is out of sync.
Presence detection
Flags skills that exist in Claude but are missing from codex/ or gemini/, or skills in mirrors with missing source-version stamps.
Design Principles
Source of truth
claude/ is always the canonical source. All truth comes from here; mirrors are caches of intentional decisions, never authoritative.
Manual gate on mirrors
Mirrors do not auto-sync. Each mirror creation or update is an intentional human action (running a command), ensuring deliberate control over what propagates.
Observability over automation
/audit-skills provides visibility into gaps without forcing sync. Humans decide when/if to close gaps based on the report.
Versioning is explicit
Every mirror-to-source relationship is versioned and stamped, making it easy to see exactly which Claude skill version a mirror copied and when.
