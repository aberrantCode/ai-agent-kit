Boundary Sentences · ownership articulation
project-manager ↔ agent-manager: project-manager owns single-agent multi-turn loop composition and durable state files; agent-manager owns multi-agent dispatch, recovery, and session-JSONL infrastructure.
gated-batch ↔ project-manager: gated-batch owns per-item data-plane state; project-manager owns session-plane resumption.
quality-manager ↔ developer-manager ↔ ops-manager: quality-manager owns observe-and-judge + pre-ship smoke; developer-manager owns launch; ops-manager owns post-deploy verification.
design-manager ↔ quality-manager: design-manager owns 'is it good'; quality-manager owns 'does it work'.
