A new slash command name starts in unassigned. Before assignment, it must pass the Generic-Verb Rule: bare generic verbs/nouns (like /apply, /probe, /dashboard) are renamed to specific verb–object pairs (/apply-script, /probe-incident, /add-dashboard). After passing, it transitions to exactly one of three terminal states: global, bundle-owned, or cut.
Terminal States
Global
Lives in claude/commands/. No single bundle owns it. Used across multiple domains.
Bundle-Owned
Moves into a specific bundle's commands/ directory. Owned and versioned by that bundle.
Cut
Rejected or retired. Does not ship. Removed from the command namespace registry.
Examples & Rules
  • Global example: /diff-review, /plan, commands marked "review at closeout" in the registry.
  • Bundle-owned example: /code-review → quality-manager bundle, /ship stays github-owned.
  • Cut examples: /verify (built-in verify skill + superpowers owned it), /guide, /profile-perf, /check-mirrors.
  • Collision rule: Built-ins and plugins win naming silently. /verify was cut; /init was renamed to /init-repo to avoid collision with Claude Code's built-in.
