Session Manager

session lifecycle bundle · start → during → end → after · one shared transcript parser

Ownership · routing head, not a runtime gate
session-manager owns session handoff, durable session state, and session-JSONL infrastructure. Each sub-skill triggers on its own description and each command loads exactly one sub-skill. Handoff moves work forward; audit, mine, delegation-ledger and usage look backward. Not here: composing /loop or iteration prompts, feature specs, plans and task files (project-manager).
resume→ checkpoint→ handoff→ dispatch→ retire→ audit / mine / delegation-ledger / usage
ten sub-skills, one per stage
Start · reading back
  • resume
    Reconstruct where you left off
    Recent transcripts + git state; propose (or auto-run) the next action. Commands: /work-resume · /work-resume-auto · /work-report · /work-scan.
work begins
During · durable state
  • checkpoint
    Single state-file convention
    Tiered summaries, one step per turn, recorded evidence, and a resume prompt, so work survives context resets, /loop iterations and multi-session tasks.
work ends
End · handing off
  • handoff
    Write the prompt for the next session
    Launch, scope, copy, and chain modes.
  • dispatch
    Worktree + new terminal tab
    Create a per-task worktree and launch any prompt file (including a human-written one) in a new terminal tab; verify the launch. Depends on spawn-terminal.
  • retire
    Post-merge cleanup gate
    Five checks; -Confirmed is human-only.
Dependency: dispatch delegates tab spawning to the standalone spawn-terminal skill, which this bundle requires:.
afterwards
After · looking backward
  • audit
    Check past sessions against a stated rule
    Read-only. A named rule (“did we follow X”) goes here.
  • mine
    Friction mode and knowledge mode
    Friction: recurring mistakes → proposed patches. Knowledge: domain knowledge from history. No named rule.
  • delegation-ledger
    Delegated-subagent outcomes
    Record and report outcomes in ~/.claude/telemetry/delegation-outcomes.jsonl.
  • usage
    Token cost
    Historical burn and the per-session startup baseline.
shared foundation underneath every stage
Shared · transcripts
  • transcripts
    cc_transcripts.py, the one stdlib JSONL library
    Every script in the bundle imports it (documented for skill authors). Feeds resume, audit, mine and usage.

Routing rules
  • Forward vs backward: “hand this audit off” is a handoff of an audit task, not an audit.
  • Audit vs mine: a named rule → audit; no rule, just “what keeps going wrong” → mine.
  • Resume vs checkpoint: checkpoint writes durable state during work; resume reads it when you come back.
  • Handoff vs dispatch: handoff writes the prompt; dispatch launches a prompt file.
  • Genuinely ambiguous between two stages → ask, do not guess.
