YouTube Toolkit

Drop a YouTube link, pick actions from an AskUserQuestion menu, and run them through a hardened yt-dlp + ffmpeg pipeline. Split a video by chapters, then splice clips from several split videos into one mix.

Workflow

0 Preflightpreflight.sh
yt-dlp / ffmpeg / node, curl_cffi
→
1 Probeprobe.sh
title, duration, chapters, slug
→
2 AskmultiSelect menu: video, subs, metadata, split; follow-ups for quality / method
→
3 Downloaddownload.sh
video + meta first, subtitles in a second pass
4 Split by chaptersgenerate-cuts.py
info.json → chapters.txt + cut-chapters.sh
MODE=reencode (precise 1080p) or copy (keyframe)
→
5 Splice clipssplice_clips.py
groups → exclude → pick → interleave → one ffmpeg concat re-encode

Splice at a glance

Inputs

--group LABEL=DIR (repeatable), a sections/ folder each. --exclude substrings, --pick N|LABEL=N, --seed.

Interleave

Round-robin across groups; the longer group's leftovers follow in order.
A1 B1 C1 A2 B2 C2 A3 ...

Normalise + encode

scale/pad 1080p, SAR 1, 30 fps, 48 kHz stereo, then one libx264 / AAC concat pass. --dry-run previews the command.
